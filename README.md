## 구현

- 비공개 `softm/jeonhwahannun.android`에 실제 수집 코드와 Android 앱 소스를 저장합니다.
- 매주 월요일 06:23 KST에 수집하고 라이선스·자료 기준일·CSV 스키마·번호 형식·중복·공유번호·급감을 검사합니다.
- 수집 원본, 후보 자료, SQLite DB, 변경 내역과 체크섬은 만료 없는 비공개 GitHub Release로 보존합니다. Actions artifact는 30일 보관하는 사본입니다.
- Android는 인터넷 없이 포함된 DB를 조회합니다. 기관명·번호 검색, 출처·기준일 표시, 개인 차단·해제와 CallScreeningService 수신 처리를 구현했습니다.
- 기기에서 역할·팝업 권한을 허용해야 수신 정보가 표시됩니다. 잠금화면과 제조사별 동작은 실기기 검증 대상입니다.

기관 번호와의 연결은 실제 발신자 신원을 인증하지 않습니다. 스팸 신고 서버나 안전 번호 판정을 제공하는 DB가 아닙니다. 사용자 연락처·수신 번호·개인 차단목록을 서버로 업로드하지 않습니다.

웹 화면과 GitHub Pages 공개 검색 배포는 아직 포함하지 않았습니다. 이 공개 저장소에는 사용자 개인정보나 수집 원본 전체를 저장하지 않습니다.
